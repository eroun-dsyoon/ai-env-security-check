회사에서 쓰는 AI,
전부 파악하고 있나요?

회사에서 쓰는 모든 AI 환경을 찾아 점검하고, 우리 회사에 어떤 보안위협이 있는지 검토하는 체크 도구입니다. 웹 AI 서비스, 개발 도구, 사내 시스템 연동, 업무 도구에 내장된 AI, 승인 없이 쓰는 그림자 AI까지 7개 범주 30종을 다룹니다. 환경별 담당자가 통제 항목과 보안 이슈를 확인하면 위험 순위·부족한 보안기술·개선 로드맵을 담은 종합 리포트가 나옵니다.

모든 응답은 브라우저 안에서만 처리됩니다. 서버 전송·외부 호출이 없습니다. 용어 옆 ? 버튼을 누르면 설명이 나옵니다.

진행 순서

  1. 1
    환경 발굴
    7개 범주 30종 환경 중 사용 중인 것을 모두 선택하고, 목록에 없으면 직접 추가
  2. 2
    전사 공통 통제
    정책·계약·교육·사고대응 등 환경과 무관하게 한 번만 확인하는 14개 항목
  3. 3
    환경별 점검
    환경마다 담당 관리자가 프로파일 4문항 + 통제 항목 + 정보보안 이슈를 체크
  4. 4
    보안기술 점검
    선택한 환경에 필요한 보안기술·제품군 26종 중 보유 현황을 체크
  5. 5
    종합 리포트
    위험 매트릭스, 조직 점수, 이슈, 부족한 보안기술 추천, 개선 로드맵 — HTML·PDF로 저장

왜 ‘환경별’로 나눠야 하나요

같은 AI라도 데이터가 어디로 흐르는지가 환경마다 완전히 다릅니다. 코딩 에이전트는 저장소와 셸에, 웹 챗봇은 브라우저 붙여넣기에, 내부 API 연동은 운영 DB에 닿아 있습니다. 하나의 체크리스트로 뭉뚱그리면 가장 위험한 환경이 가장 느슨한 답변에 묻힙니다.

점수 산출 방식

구성의미범위
환경 잠재위험환경 유형의 구조적 위험도 + 데이터 등급·권한·사용자 범위·규제 답변으로 산출0–100
환경 통제율그 환경에 적용되는 통제 항목의 가중 달성률 (예 1.0 / 부분 0.5 / 아니오·모름 0)0–100%
환경 잔여위험잠재위험 × (1 − 통제율 × 0.9) × (1 + 필수 통제 미달률 × 0.5). 잠재위험을 넘지 않으며, 필수 항목 미비 1개당 6점의 하한을 적용0–100
이슈 가산‘정보보안 이슈’ 체크에서 발견된 항목의 심각도 합계(치명 5·중대 3·경미 1점, 최대 20점)0–20
조직 종합점수환경 위험점수(잔여위험 + 이슈 가산)를 노출 가중치(사용자 범위·데이터 등급 답변)로 가중 평균하고, 전사 공통 통제 미비분(최대 15점)을 더함0–100
보안기술 확보율선택한 환경에 필요한 보안기술 중 보유 비율(필수 2배·권장 1배 가중). 위험 점수와 별도로 표시0–100%
ℹ
점수는 절대 등급이 아니라 우선순위 도구입니다. 목표는 100점이 아니라 가장 위험한 환경 3개의 잔여위험을 40점 이하로 낮추는 것입니다.

전사 공통 통제 점검

환경이 몇 개든 한 번만 확인하면 되는 항목입니다. 보통 정보보호 담당자·CISO가 답합니다.

STEP 3 / 5

환경별 관리자 점검

환경마다 프로파일 → 통제 → 정보보안 이슈 순서로 확인합니다. 확신이 없으면 ‘모름’을 선택하세요.

STEP 4 / 5

보안기술·제품군 보유 점검

1단계에서 선택한 환경에 필요한 보안기술만 표시합니다. 회사가 쓰고 있는지 고르고, 쓰는 제품명을 적어 두세요. 모르면 ‘모름’을 고르고 각 기술의 ? 설명을 참고하세요.

참고 — 근거 기준

본 도구는 자체 점검용이며 법률 자문이나 인증 심사 결과를 대체하지 않습니다. 가중치와 기준은 조직의 데이터 등급 체계에 맞게 조정해 사용하세요. 응답 데이터는 브라우저를 벗어나지 않으며, ‘결과 저장’을 누를 때만 로컬 파일로 내려받습니다.

조정 방법(선택) — 파일을 텍스트 편집기로 열어 ENV_TYPES의 baseRisk(환경 유형별 구조적 위험), PROFILE_Q의 가중치, 각 통제 항목의 w(1=보완 / 2=중요 / 3=필수), PARTIAL_CREDIT(부분 응답 인정 비율), TECH의 need(범주별 보안기술 필요도 2=필수 / 1=권장)를 조직 기준으로 바꾼 뒤 저장하면 됩니다.
